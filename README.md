## 面板服和 VPS 差在哪，你该买哪个

面板服是把服务端装进一个已经配好的容器里，商家负责系统、面板和运行环境，你只负责服务端本身。VPS 是一台完整的云主机，系统、Java、面板、防火墙都得自己装，好处是想开几个服就开几个。

| 对比项 | 面板服 | VPS |
| --- | --- | --- |
| 操作方式 | 网页面板（MCSM、翼龙这类） | SSH 登录，命令行 |
| 能开几个服 | 一般一个实例一个服 | 装 Docker 后按内存自行多开 |
| 端口 | 商家分配，通常一个 | 可开十几个，自己映射 |
| 适合谁 | 单端、朋友联机、新手 | 公开服、多端、还要跑别的服务 |
| 出问题谁负责 | 系统和面板由商家管 | 系统层自己排查 |

判断标准很直接：如果你只打算开一个服，而且不想碰 `systemctl`、防火墙、Docker 这些词，面板服省下来的时间比省下的钱值钱。反过来，如果你计划同时开一个生存服加一个模组服，面板服要买两份，VPS 一份就够，这时候 VPS 更划算。

## 档位怎么挑：4 核 8G 是不是必须的

不是。配置需求由版本和模组数量决定，不由“开服”这件事本身决定。原版生存两三个人，2 核 4G 就能跑；1.20 这类高版本再叠十几个模组，4 核 8G 是比较稳的起步档，再往上加人加模组才需要更高配置。

| 你的情况 | 档位方向 | 下单前要确认的 |
| --- | --- | --- |
| 原版生存，2–5 人 | 2 核 4G 起 | 内存不低于 2G，Java 版本对上 |
| 1.20 高版本 + 十来个模组，5–10 人 | 4 核 8G | 单核主频、硬盘是不是 SSD |
| 大型整合包（Create、ATM 这类） | 4 核 8G 以上 | 内存优先，整合包吃内存比吃 CPU 狠 |
| 基岩版联机 | 2 核 2G 起 | 端口映射协议要选 tcp+udp |

模组服比原版吃内存，这是选档时最容易低估的一项。整合包启动时要把几百个模组加载进内存，4G 的机器开 1.20 整合包，很可能在启动阶段就 OOM。宁可先买大一号，跑起来看面板的内存曲线，长期占用稳定在 70% 以下就不用再升。

## Java 版本选错，服务端直接起不来

面板服下单时通常要选一个 Java 版本，这个不能随便点。选低了服务端报 `Unsupported class file major version`，选高了老版本核心同样跑不起来。

| Minecraft 版本 | JDK |
| --- | --- |
| 1.16.5 以下 | Java 8 |
| 1.16.5 | Java 11 |
| 1.17 及以上 | Java 17 |

如果商家提供的是“纯 Java 环境”而不是一键开服列表，你需要自己上传核心 jar 并写启动命令。一键开服列表里通常有 Arclight、Mohist、CatServer、Fabric、Paper 这些，Forge 原版反而经常不在列表里，得走纯 Java 环境手动装。

## 从上传 jar 到进游戏：必改的几个地方

以 Forge 1.20.2 为例，流程是这样的。

1. **上传核心**。在文件管理里上传 `forge-1.20.2-xx.x.x-installer.jar`。
2. **改启动脚本**。把启动命令换成安装命令：

bash
java -Xms128M -XX:MaxRAMPercentage=95.0 -Dfile.encoding=UTF-8 \
-Duser.language=zh -Duser.country=CN \
-jar forge-1.20.2-48.0.30-installer.jar --installServer


`--installServer` 是关键，少了它服务端不会去下载库文件。官方原版服务端不需要这一步，把 `--installServer` 去掉直接跑就行。

3. **等安装完成**。终端出现 `The server installed successfully`，文件列表里会多出 `run.sh`。
4. **改 `run.sh`**。删掉里面的 `@user_jvm_args.txt`，换成 `-Xms128M -XX:MaxRAMPercentage=95.0 -Dfile.encoding=UTF-8 -Duser.language=zh -Duser.country=CN`，注意用空格分隔。然后把启动脚本改成 `bash run.sh`。
5. **同意 EULA**。第一次启动会提示 `You need to agree to the EULA`，打开 `eula.txt` 把 `eula=false` 改成 `eula=true`。
6. **改端口**。这一条最容易漏。打开 `server.properties`，把 `server-port=25565` 改成面板控制台右上角地址里冒号后面那个端口号。不改的话服务端在容器里正常跑，外面连不进来。

`-XX:MaxRAMPercentage=95.0` 的意思是 JVM 最多用掉可用内存的 95%。买 4G 的机器，服务端最多吃约 3.8G，剩下的留给系统和面板进程。这个比例比自己手写 `-Xmx` 更省心，换配置也不用改命令。

顺带一提，`online-mode=true` 改成 `false` 就关了正版验证，盗版客户端才能进。公开服不建议关。

## 三个真正会卡住新手的地方

**库文件下载失败。** Forge 安装阶段要从国外源拉几百个库文件，国内机器有一定概率中断。表现是安装跑了一半报错退出。解决办法是找一份已经装好库文件的整合包，解压后把文件覆盖到根目录，再直接执行 `bash run.sh`。

**端口映射协议选错。** Java 版走 TCP，基岩版走 UDP。基岩版在端口映射里只选 TCP，客户端会一直显示“正在连接”然后超时。选 tcp+udp 最省事。

**防火墙没放行。** 面板服一般由商家处理，VPS 需要自己关掉或放行端口。面板服如果遇到面板能打开、游戏连不上，先回到控制台核对端口号，再检查服务端是否真的启动完成（控制台出现 `Done`）。

## 按天还是按月，这笔账怎么算

面板服常见的计费方式有两种：按固定周期付（日付、月付、年付），和按实际 CPU 消耗每天结算。前者预算确定，后者适合偶尔开服的场景。

如果你只在周末和朋友玩，日付或动态计费更合适，一个月开八九天，花费比包月低。如果服务器要长期挂着给别人进，月付或年付单价更低，年付通常还有额外折扣。下单前确认一件事：续费价和首单价是不是同一个数。有些商家首月做活动，续费恢复原价，长期开的成本要按续费价算。

另外确认退款和试用政策。能先试用一天的，就先试用，把服务端跑起来、确认端口和 Java 版本都合适，再决定买多久。

## 常见问题

**面板服能装模组吗？** 能。选纯 Java 环境，按上面的流程装 Forge 或 Fabric，模组放进 `mods` 文件夹。一键开服列表里的 Mohist、CatServer 这类混合端也支持插件加模组，但兼容性不如纯 Forge。

**存档在哪？** 文件管理里的 `world` 文件夹。换服或升级前先把这个文件夹下载下来。

**能换版本吗？** 面板服一般支持重装或切换游戏服，换版本时注意同步换 Java 版本，1.16.5 和 1.20 用的 JDK 不一样。

**朋友连不上，先查什么？** 先看控制台有没有 `Done`，再看 `server-port` 是不是改成了商家分配的端口，最后确认地址填的是控制台显示的那个域名加端口，中间用英文冒号。
